# Atoms

더 이상 쪼갤 수 없는 최소 UI 단위. 대부분 단일 책임을 가지며, molecules·organisms의 재료가 된다.
소스 기준으로는 primitives 계층에 대응한다.

## 서브그룹

| 서브그룹 | 개요 | 인덱스 |
|---|---|---|
| buttons | 클릭으로 동작을 트리거하는 버튼 계열 | [buttons/](./buttons/README.md) |
| status | 상태·라벨을 표시하는 배지·태그·칩 | [status/](./status/README.md) |
| form-controls | 단일 값 토글·선택 컨트롤 | [form-controls/](./form-controls/README.md) |
| loading | 로딩·대기 상태 표시 | [loading/](./loading/README.md) |
| display | 보조 정보·미디어를 얹는 표시 요소 | [display/](./display/README.md) |
