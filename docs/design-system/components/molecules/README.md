# Molecules

atoms를 묶어 하나의 목적을 갖는 재사용 단위 컨트롤. 폼 입력·선택·탐색·피드백 등 화면에서 반복 사용되는 조합 단위다.
소스 기준으로는 primitives 조합 또는 가벼운 composed에 대응한다.
