# Foundation — 접근성 (a11y)

> **목적:** "무엇이 Radix로 자동 보장되고, 무엇이 호출부 책임인가"의 경계를 명확히 한다. ui-kit의 인터랙티브 컴포넌트는 대부분 Radix UI 기반이라 키보드·포커스·role을 자동 처리하지만, 라벨링·상태 텍스트·색 외 의미전달은 **호출부가 반드시 채워야** 한다.
>
> 상위 원칙은 [principles.md](principles.md) §접근성 참조.

## 경계 — Radix 자동 보장 vs 호출부 책임

Dialog·Popover·DropdownMenu·Tooltip·Tabs·Accordion·RadioGroup·Switch·Checkbox·Select 등은 Radix UI 위에 빌드된다.

| Radix가 자동 보장 (그대로 신뢰) | 호출부 / 컴포넌트 작성자 책임 (직접 채움) |
|---|---|
| 오버레이 **focus trap** (열림 시 내부 가둠, 닫힘 시 트리거로 복귀) | 컨트롤의 **접근 가능한 이름**(`aria-label` 또는 연결된 label) |
| **키보드 조작**(방향키·Enter·Space·Esc·타입어헤드) | 정렬·선택 등 **상태의 스크린리더 노출**(필요 시 `aria-sort`·`aria-current` 보강) |
| **role·aria-expanded·aria-selected** 등 위젯 role 배선 | **색만으로 의미 전달 금지** — 아이콘·텍스트 병기 |
| Esc·바깥 클릭 닫힘, 스크롤 잠금 | native 활성화가 없는 요소(`span[role="button"]`)의 **onKeyDown** |
| focusable 요소 간 Tab 순서 | 커스텀 인터랙티브 요소의 **focus-visible 표시** |

> ⚠️ Radix는 "위젯이 동작하게" 만들 뿐 "그것이 무엇인지 말해주지" 않는다. 라벨·상태 텍스트는 항상 호출부가 넣는다.

## 핵심 체크 — 영역별

### Overlay (Dialog · Popover)
- 제목을 Dialog title로 제공 — 스크린리더가 오버레이 이름으로 읽는다.
- 닫기(×) 버튼에 `aria-label="닫기"`. 아이콘만 있는 버튼은 텍스트 라벨이 없으므로 필수.
- focus trap·Esc 닫힘·트리거 복귀는 Radix가 처리 → 직접 구현 금지(이중 처리로 깨짐).

### Form (Input · Select · Checkbox · RadioGroup · Switch)
- 모든 입력은 라벨과 연결 — `htmlFor`/`id`로 묶거나, 보이는 라벨이 없으면 `aria-label`.
- 에러는 색뿐 아니라 **에러 텍스트**로도 전달. 도움말·에러 메시지는 `aria-describedby`로 연결.
- 마우스 전용 보조 버튼(clear ×·비밀번호 eye 토글)은 `tabIndex={-1}`로 Tab 순서에서 제외.

### Navigation (Tabs · DropdownMenu)
- 방향키 이동·`aria-selected`/`aria-expanded`는 Radix 자동 → 신뢰.
- 현재 위치는 색 외에 텍스트·아이콘·`aria-current`로도 구분.
- 아이콘만 있는 탭/메뉴 항목에는 접근 가능한 이름(`aria-label` 또는 시각적으로만 숨긴 텍스트) 부여.

### 데이터 표시 (목록·테이블)
- 정렬·선택 상태를 아이콘 **색만으로** 표현하지 않는다(아이콘 형태·방향 병기).
- 정렬 가능한 헤더에 스크린리더 정렬 상태가 필요하면 `aria-sort`를 호출부가 보강한다(자동으로 붙지 않음).
- 선택 체크박스에는 `aria-label`(전체 선택·행 선택)을 부여한다.

## 포커스 표시

- 커스텀 요소에서 `outline`을 제거할 때는 반드시 대체 표시를 넣는다.
- 포커스 링은 `--color-border-focus`(brand-400) + offset 사용.

```tsx
<button
  className="
    focus-visible:outline-none
    focus-visible:ring-2
    focus-visible:ring-[var(--color-border-focus)]
    focus-visible:ring-offset-2
  "
/>
```

## 규칙 요약
- 모든 인터랙티브 요소는 **키보드만으로 조작 가능**.
- **색만으로 의미를 전달하지 않는다** — 상태색에는 항상 아이콘·텍스트 병기.
- 포커스가 보이게(`focus-visible`) — outline 제거 시 대체 표시 필수.
- Radix가 보장하는 동작(focus trap·키보드·role)을 재구현하지 않는다.
- 큰 모션은 `prefers-reduced-motion`을 존중한다([motion.md](motion.md)).
