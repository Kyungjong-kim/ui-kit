# 에이전트 컨텍스트 문서

이 폴더의 문서는 에이전트가 작업 시작 시 읽어 ui-kit의 구조·규칙·디자인 시스템을 파악하기 위한 인덱스입니다.

| 문서 | 역할 |
|------|------|
| `architecture.md` | 라이브러리 빌드·exports·peerDependencies·의존성 구조 |
| `conventions.md` | biome 포매팅, 파일·컴포넌트 네이밍, forwardRef 패턴 |
| `design-system.md` | 디자인 토큰 구조, variant(cva) 패턴, 토큰 사용 규칙 |
| `ui-kit-dev.md` | 컴포넌트 작성 전담 에이전트 정의 (`.claude/agents/`에 위치) |
| `ui-kit-doc-writer.md` | 문서 갱신 전담 에이전트 정의 (`.claude/agents/`에 위치) |
