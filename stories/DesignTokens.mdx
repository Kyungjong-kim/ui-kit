# Design Tokens

ui-kit 는 **2계층 토큰** 구조를 따른다. 컴포넌트는 **semantic 토큰만** 참조한다.

```
src/styles/tokens/
├── core.css       # raw 값 (#fabc37 등) — 직접 참조 금지
└── semantic.css   # core 참조 의미 토큰 — 컴포넌트가 사용
```

> 아래 카탈로그의 색 값은 `core.css` · `semantic.css` 소스와 동일하다. 각 스와치는 실제 CSS 변수를 렌더하므로 다크모드 토글(맨 아래) 시 semantic 계열이 함께 반응한다.

export const Section = ({ title, children }) => (
  <div style={{ margin: "1.5rem 0" }}>
    {title && (
      <h4 style={{ margin: "0 0 0.5rem", fontFamily: "system-ui, sans-serif", fontSize: "0.95rem", fontWeight: 700 }}>
        {title}
      </h4>
    )}
    {children}
  </div>
);

export const PaletteRow = ({ name }) => {
  const p = PALETTES[name];
  return (
    <div style={{ margin: "0 0 1.25rem" }}>
      <div style={{ fontFamily: "system-ui, sans-serif", fontSize: "0.85rem", fontWeight: 700 }}>{p.label}</div>
      <div style={{ fontFamily: "system-ui, sans-serif", fontSize: "0.75rem", color: "#635e58", margin: "0.1rem 0 0.4rem" }}>{p.note}</div>
      <div style={{ display: "flex", flexWrap: "wrap", gap: "0.5rem" }}>
        {SCALE.map((step) => {
          const hex = p.hex[step];
          const dark = step >= 400;
          return (
            <div key={step} style={{ width: "5.25rem" }}>
              <div
                title={`--color-${name}-${step}`}
                style={{
                  height: "3rem",
                  background: hex,
                  borderRadius: "0.375rem",
                  border: "1px solid rgba(0,0,0,0.08)",
                  display: "flex",
                  alignItems: "flex-end",
                  padding: "0.25rem",
                  color: dark ? "#fff" : "#141210",
                  fontFamily: "system-ui, sans-serif",
                  fontSize: "0.7rem",
                  fontWeight: 600,
                }}
              >
                {step}
              </div>
              <div style={{ fontFamily: "monospace", fontSize: "0.65rem", color: "#635e58", marginTop: "0.2rem" }}>{hex}</div>
            </div>
          );
        })}
      </div>
    </div>
  );
};

## 2. semantic.css — 의미 토큰 (실사용)

컴포넌트가 참조하는 유일한 계층. 각 토큰은 core 값을 `var()`로 가리킨다. 아래 스와치는 실제 CSS 변수를 렌더한다.

## 7. 다크모드 (`[data-theme="dark"]`)

`semantic.css` 는 `[data-theme="dark"]` 셀렉터로 text·bg·surface·border·icon 계열을 재정의한다. 아래 패널은 자체 스코프에 `data-theme` 를 적용해 라이트/다크를 비교한다.

export const DEMO_TOKENS = [
  { name: "--color-text-primary", kind: "text", label: "Primary text" },
  { name: "--color-text-secondary", kind: "text", label: "Secondary text" },
  { name: "--color-text-brand-default", kind: "text", label: "Brand text" },
  { name: "--color-bg-primary", kind: "bg", label: "bg-primary" },
  { name: "--color-bg-secondary", kind: "bg", label: "bg-secondary" },
  { name: "--color-bg-brand-subtle", kind: "bg", label: "bg-brand-subtle" },
  { name: "--color-border-default", kind: "border", label: "border-default" },
  { name: "--token-color-surface-strong", kind: "bg", label: "surface-strong" },
];

export const ThemePanel = ({ theme }) => (
  <div
    data-theme={theme}
    style={{
      flex: "1 1 18rem",
      background: "var(--color-bg-primary)",
      border: "1px solid var(--color-border-default)",
      borderRadius: "var(--token-radius-md)",
      padding: "1rem",
      boxShadow: "var(--token-shadow-default-sm)",
    }}
  >
    <div style={{ fontFamily: "system-ui, sans-serif", fontSize: "0.8rem", fontWeight: 700, color: "var(--color-text-primary)", marginBottom: "0.6rem" }}>
      {theme === "dark" ? "다크 (data-theme=dark)" : "라이트 (:root)"}
    </div>
    {DEMO_TOKENS.map((t) => (
      <div key={t.name} style={{ display: "flex", alignItems: "center", gap: "0.6rem", padding: "0.2rem 0" }}>
        {t.kind === "text" ? (
          <span style={{ color: `var(${t.name})`, fontSize: "0.85rem", fontWeight: 600, minWidth: "8rem" }}>{t.label}</span>
        ) : (
          <>
            <div style={{
              width: "2rem", height: "1.4rem",
              background: t.kind === "bg" ? `var(${t.name})` : "var(--color-bg-primary)",
              border: t.kind === "border" ? `2px solid var(${t.name})` : "1px solid var(--color-border-default)",
              borderRadius: "0.25rem",
            }} />
            <span style={{ fontSize: "0.85rem", color: "var(--color-text-secondary)", minWidth: "8rem" }}>{t.label}</span>
          </>
        )}
        <span style={{ fontFamily: "monospace", fontSize: "0.62rem", color: "var(--color-text-tertiary)" }}>{t.name.replace("--color-", "").replace("--token-color-", "")}</span>
      </div>
    ))}
  </div>
);

export const DarkModeCompare = () => {
  const [theme, setTheme] = useState("side-by-side");
  return (
    <div>
      <div style={{ display: "flex", gap: "0.5rem", marginBottom: "0.75rem" }}>
        {["side-by-side", "light", "dark"].map((mode) => (
          <button
            key={mode}
            onClick={() => setTheme(mode)}
            style={{
              padding: "0.35rem 0.8rem",
              fontFamily: "system-ui, sans-serif",
              fontSize: "0.75rem",
              fontWeight: 600,
              cursor: "pointer",
              borderRadius: "var(--token-radius-sm)",
              border: "1px solid var(--color-border-default)",
              background: theme === mode ? "var(--color-bg-brand-default)" : "var(--color-bg-primary)",
              color: theme === mode ? "var(--color-interactive-primary-text)" : "var(--color-text-secondary)",
            }}
          >
            {mode === "side-by-side" ? "나란히 비교" : mode === "light" ? "라이트" : "다크"}

        ))}

      </div>
    </div>
  );
};

## 8. 사용 원칙

| 규칙 | 위반 예 | 올바른 예 |
|---|---|---|
| 하드코딩 색상 금지 | `bg-[#fabc37]` | `bg-[var(--color-bg-brand-default)]` |
| core 토큰 직접 사용 금지 | `bg-brand-500` | `bg-[var(--color-bg-brand-default)]` |
| 임의 px 금지 | `p-[7px]` · `text-[14px]` | `px-inline-md` · `typography-body-md-base` |
| 새 색상은 토큰 먼저 추가 | 컴포넌트에 직접 색상 정의 | `tokens/semantic.css` 에 토큰 추가 후 참조 |

> 전체 토큰 카탈로그·추가 절차: 레포 `docs/design-system/tokens/`(`_convention` · `core` · `semantic`) 및 `docs/design-system/foundation/`(`color` · `typography`).

## 9. Tailwind v4 연동

라이브러리 내부 컴포넌트는 항상 `[var(--...)]` 형태(CSS 임의값)를 사용한다.
소비 앱이 `@theme inline` 으로 토큰을 노출하면 `bg-bg-brand-default` 형태 utility 도 동작.

```css
/* 소비 앱 example: app.css */
@import "tailwindcss";
@import "ui-kit/styles";
@import "ui-kit/theme";   /* @theme inline 매핑 — 커스텀 유틸 생성 */
```
