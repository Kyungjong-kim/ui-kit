# Design Tokens

ui-kit 는 **2계층 토큰** 구조를 따른다. 컴포넌트는 **semantic 토큰만** 참조한다.

```
src/styles/tokens/
├── core.css       # raw 값 (#fabc37 등) — 직접 참조 금지
└── semantic.css   # core 참조 의미 토큰 — 컴포넌트가 사용
```

## 1. core.css — raw 색상 카테고리

| 카테고리 | 변수 prefix | 단계 |
|---|---|---|
| brand | `--color-brand-*` | 25, 50, 100~900 |
| neutral | `--color-neutral-*` | 25, 50, 100~900 |
| red / green / orange / blue | `--color-{name}-*` | 25, 50, 100~900 |
| white / black | `--color-white`, `--color-black` | — |

### Interactive

interactive 토큰은 버튼 등 상호작용 컴포넌트가 `bg`·`bg-hover`·`text`·`border` 4종을 묶어서 참조.

| 프리셋 | 사용처 |
|---|---|
| `--color-interactive-primary-*` | Primary Button (브랜드 강조) |
| `--color-interactive-secondary-*` | Secondary Button (외곽선) |
| `--color-interactive-ghost-*` | Ghost Button (배경 호버만) |
| `--color-interactive-destructive-*` | Destructive Button (삭제·경고) |

## 3. 사용 원칙

| 규칙 | 위반 예 | 올바른 예 |
|---|---|---|
| 하드코딩 색상 금지 | `bg-[#fabc37]` | `bg-[var(--color-bg-brand-default)]` |
| core 토큰 직접 사용 금지 | `bg-brand-500` | `bg-[var(--color-bg-brand-default)]` |
| 새 색상은 토큰 먼저 추가 | 컴포넌트에 직접 색상 정의 | `tokens/semantic.css` 에 토큰 추가 후 참조 |

## 4. Tailwind v4 연동

라이브러리 내부 컴포넌트는 항상 `[var(--...)]` 형태(CSS 임의값)를 사용한다.
소비 앱이 `@theme inline` 으로 토큰을 노출하면 `bg-bg-brand-default` 형태 utility 도 동작.

```css
/* 소비 앱 example: app.css */
@import "tailwindcss";
@import "ui-kit/styles";

@theme inline {
  --color-bg-brand-default: var(--color-bg-brand-default);
  /* ... 필요한 토큰 노출 */
}
```
